# 🧩 Алгоритмы и структуры данных · ИТМО

Решения учебных контестов на Python. Каждая задача — самостоятельный файл со стандартным вводом и выводом.

| Контест | Темы | Решения |
| --- | --- | --- |
| [01](contests/contest-01) | Матрицы, остатки, максимальные суммы | 6 файлов |
| [02](contests/contest-02) | Очередь, дек, стек, польская запись | 4 файла |
| [03](contests/contest-03) | Рекурсия, подмножества, сочетания, Ханой | 5 решений и заготовка «Ферзи» |

## Запуск

Нужен Python 3, внешних библиотек нет:

```sh
python contests/contest-02/1_quque.py
```

Вводите данные в формате конкретной задачи. Условия и ограничения контестов не приложены, поэтому прохождение всех тестов проверяющей системы здесь не заявляется.

## Статус

Исходники перенесены из локальных работ автора. В «змейке» исправлены смешанные отступы и граница прохода по левому столбцу. Файл `6_queen.py` был пустым и отмечен как заготовка. Остальные решения сохранены без изменения алгоритмов.

Синтаксис всех файлов проверен. Для «змейки» проверены квадратные и прямоугольные матрицы, одна строка и один столбец.
